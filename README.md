# Telegram чат · GREEN-API

Приложение для отправки и получения текстовых сообщений Telegram через GREEN-API.

## Как запустить проект

Перед запуском установите Node.js 24 LTS и Git. npm устанавливается вместе с Node.js.

**1. Скачайте проект и перейдите в его папку:**

```sh
git clone https://github.com/quester16/green-api.git
cd green-api
```

Если проект уже скачан, просто откройте терминал в его папке.

**2. Установите зависимости:**

```sh
npm ci
```

**3. Запустите приложение:**

```sh
npm run dev
```

**4. Откройте в браузере адрес из терминала.** Обычно это [http://localhost:5173](http://localhost:5173). Если порт занят, Vite покажет другой адрес. Пока вы пользуетесь приложением, оставьте терминал открытым. Для остановки нажмите `Ctrl+C`.

Чтобы проверить готовую сборку, выполните:

```sh
npm run build
npm run preview
```

После этого откройте адрес, который появится в терминале. Отдельная база данных и сервер не нужны, но для обмена сообщениями требуется интернет.

## Как пользоваться приложением

### 1. Подготовьте аккаунт GREEN-API

1. Откройте [личный кабинет GREEN-API](https://console.green-api.com/).
2. Создайте инстанс для **Telegram** — подключение вашего аккаунта к сервису — и авторизуйте Telegram по инструкции в кабинете.
3. В настройках инстанса включите получение входящих сообщений (`incomingWebhook`). Поле адреса webhook (`webhookUrl`) оставьте пустым. Сохраните настройки и дождитесь их применения.
4. Для получения уведомлений об ошибках доставки включите уведомления о статусах исходящих сообщений (`outgoingWebhook`).
5. Найдите в кабинете параметры `idInstance`, `apiTokenInstance` и `apiUrl`. Они понадобятся для подключения.

### 2. Подключитесь в приложении

1. В поле **«ID инстанса»** вставьте `idInstance`.
2. В поле **«Токен доступа»** вставьте `apiTokenInstance`.
3. Раскройте **«Адрес API из кабинета»** и проверьте, что `apiUrl` совпадает с адресом вашего инстанса. Если отличается — замените его.
4. Нажмите **«Подключиться»** и дождитесь завершения проверки.

После успешного подключения появится поле **«Номер телефона собеседника»**. Если подключение не удалось, причина будет показана под областью переписки. Учётные данные вводятся только в интерфейсе — изменять файлы проекта не требуется.

### 3. Откройте чат и отправьте сообщение

1. Введите номер собеседника с кодом страны, например `+998 90 123 45 67`.
2. Нажмите **«Открыть чат»**. У собеседника должен быть Telegram, а его номер должен быть доступен для поиска.
3. Введите текст в поле **«Написать сообщение...»**.
4. Нажмите кнопку со стрелкой или `Enter`.
5. После принятия сообщения сервисом оно появится справа, а поле ввода очистится. Это ещё не подтверждение прочтения.
6. Когда собеседник ответит в Telegram, его сообщение автоматически появится слева. Нажимать кнопку получения не нужно.

Для проверки попросите собеседника ответить или используйте второй аккаунт Telegram. Чтобы открыть другую переписку, введите другой номер и снова нажмите **«Открыть чат»**.

### 4. Завершите работу

Нажмите **«Отключиться»**. Приложение остановит получение сообщений и очистит текущую переписку и токен формы.

При обновлении страницы подключение и сообщения тоже сбрасываются. История из Telegram не загружается: приложение показывает сообщения, полученные или отправленные во время текущей сессии. Поддерживаются только текстовые сообщения.

### Если что-то не работает

- **Не удаётся подключиться:** проверьте ID, токен, адрес API и авторизацию Telegram в кабинете GREEN-API.
- **Собеседник не найден:** проверьте международный формат номера и настройки приватности собеседника.
- **Ответы не появляются:** проверьте `incomingWebhook` и пустое поле `webhookUrl`. Не запускайте несколько вкладок или приложений, получающих уведомления с одного инстанса: они используют общую очередь.
- **Ошибка лимита / 466:** проверьте квоту тарифа в кабинете GREEN-API. На бесплатном тарифе количество доступных чатов ограничено.
- **Ошибка при отправке:** текст остаётся в поле. Перед повторной отправкой после таймаута проверьте Telegram — сообщение могло уже отправиться.

## Структура проекта

Основные файлы находятся в `src/components/chat/`:

| Файл | Назначение |
| --- | --- |
| `Chat.tsx` | Подключение, выбранный чат, состояние переписки и получение сообщений |
| `ConnectInstances.tsx` | Формы подключения и ввода номера собеседника |
| `Message.tsx` | Отображение одного сообщения |
| `api.ts` | Запросы GREEN-API и обработка ошибок |
| `messageUtils.ts` | Подготовка номера, разбор входящих сообщений и защита от дублей |
| `types.ts` | Общие TypeScript-типы |

В папке `tests/` находятся автоматические проверки. `netlify.toml` и `public/_redirects` содержат настройки публикации на Netlify.
